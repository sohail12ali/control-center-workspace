# Progress: CC-T003

## Status Summary
Stage: VERIFY — all five plan tasks built and tested.

## Dated Log

### 2026-08-29

**All five tasks done. 386 tests passing (107 new); harness lint clean.**

- **01 tool surface** (`agent_tools.py`) — file, search and shell tools plus every console
  verb, schemas generated by the same code the MCP server uses so an agent here and an agent
  on Claude Code see identical descriptions. Paths are `realpath`-resolved against the
  workspace root, so a symlink cannot step out; credential-shaped files are refused outright.
  Two flaws caught on review before any test ran: an operator-precedence bug in the directory
  filter that would have walked `node_modules` anyway, and a function-local import.
- **02 OpenRouter client** (`openai_client.py`) — SSE parsing and chunk assembly split from
  the HTTP so every awkward wire shape is tested with fixture text and no network: fragments
  split mid-JSON, tool arguments arriving in pieces addressed by index, parallel calls
  interleaved, usage in a final chunk with no choices, an error after a 200. Streaming bugs
  here truncate answers rather than crashing, so they survive casual use and surface later as
  "the model seems worse on this backend".
- **03 ApiSession** (`agent_api_session.py`) — the fourth transport. Emits the same
  normalized events the CLI backends do, gates through the existing approval registry
  in-process (no hook subprocess, same card), records telemetry through the CC-T001 path.
  **Caught a contract violation before it shipped:** I had `_observe` before `publish` on
  turn end; `agent_session` documents the opposite, because `_observe` drains the queue and
  draining publishes the next `turn.start` — inverted, the next turn would open at a lower
  sequence number than the turn it follows.
- **04 prompt injection** (`prompt_build.py`) — a model with no slash commands cannot resolve
  `/plan`, so the skill's text goes in the system prompt. Budgeted, and every cut is stated
  in the prompt itself: a silently truncated skill is the worst failure here, because the
  agent follows the half it received and the transcript gives no sign.
- **05 config** — `openrouter` row shipping `enabled = false` with no models listed.
  `installed` now means "the key is set" for an API backend rather than "a binary is on
  PATH", and the composer's error message comes from the backend instead of assuming a
  missing executable.
- **Defect fixed:** a job worker could die on a failed record write, silently taking the rest
  of the queue with it. Traced from a single non-reproducing thread warning; see
  [[CC-T003-verification]] for what is and is not proven about its cause.

- Done: all five tasks.
- Blocked: nothing. One gap: no live request — needs the user's key and spend.
- Next: Phase 3 (remote dispatch).
